# 🏀 CourtCentral / BasketballInfo

**CourtCentral** is a modern and elegant web application that lets you follow **NBA results in real time**, showing detailed statistics and profiles of teams, players, and games. It offers a _premium_ design and a smooth, optimized user experience. 

<img width="1875" height="929" alt="image" src="https://github.com/user-attachments/assets/e505b32a-5380-4610-a56b-7b0bbc680e34" />

## 🚀 Main Features

- **📊 Live Scores:** displays daily game results, including those currently being played, with real-time scores and live statistics. The built-in search tool also allows you to find past games played between specific teams. [Screenshot](https://github.com/user-attachments/assets/3ecc6fff-6deb-45ea-b808-24d558a56b1b)
- **📈 Detailed Statistics:** explore comprehensive team and player stats through a fast and optimized search experience. [Screenshot](https://github.com/user-attachments/assets/54d461ab-6e6d-4bee-ae25-82e343a07667)
- **🎨 Design:** presents data in a visually appealing and well-organized way, with a clean layout that makes stats easy to read and compare. [Screenshot](https://github.com/user-attachments/assets/992cb088-295d-4281-8a2a-0b6acc040ec8)

## 💻 Technology

The website is built using **React** and **Tailwind CSS**.  
To fetch real-time scores and statistics, it uses the **public [ESPN API](https://www.espn.com)**.

## 🌐 Try the Website
You can explore the live version of CourtCentral at **[courtcentral.vercel.app](https://courtcentral.vercel.app)**  
If you prefer to test it locally, simply clone the repository and open the index.html file in your browser.
